Boilerplate #

$requests is a community token named for Requests, the Python HTTP library. It is one way for people to support the open-source work of Kenneth Reitz: Requests, Responder, PyTheory, kjvstudy.org, and his Infinite State music. Kenneth didn’t create the token. Its creator fees go to his wallet, and his holding is locked; the lock is on the home page. The work itself stays free and open source. The Requests library is a Python Software Foundation project, and this token is not.

About Kenneth Reitz #

Kenneth Reitz writes software “for humans.” He created Requests, the Python HTTP library, and Pipenv, and he wrote The Hitchhiker’s Guide to Python. He was formerly Python evangelist at Heroku. Today he builds Responder and makes music with code using PyTheory. More about Kenneth.
