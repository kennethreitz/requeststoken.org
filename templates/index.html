01 — Intentions

What the coin is for

The coin is meant to celebrate and support open source, and the legacy of Requests. Transparency comes first. There is no sleight of hand.

Requests began as Kenneth’s library — “HTTP for Humans” — and the project now lives with the Python Software Foundation at github.com/psf/requests. This token is a separate thing: a memecoin on Solana. It does not change the library, and the library does not back the token.

This page does not publish a roadmap, a price target, a buyback, or a burn.
