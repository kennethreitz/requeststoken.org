A short history of Requests #

  1. OriginKenneth was working on a project that needed to make HTTP requests, and he wanted that code to be reusable. requests.py lived inside that project until he split it into its own repository in 2011.
  2. 2011Kenneth publishes Requests 0.2.0 to PyPI on February 14: “HTTP for Humans.” PyPI
  3. 2012Requests 1.0.0 is released in December. PyPI
  4. 2013Requests 2.0.0 is released on November 15. PyPI
  5. PSFThe project moves to the Python Software Foundation and is maintained at github.com/psf/requests.
